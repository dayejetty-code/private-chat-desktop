Private Chat · Windows 测试版

安装后即可从桌面或开始菜单打开，无需另行安装 .NET。
程序只安装到当前用户的账户，不需要管理员权限。

首次使用：设置本地资料库口令，等待 Tor 连接，通过邀请添加联系人并核验安全码。

这是未经独立安全审计的测试版。支持一对一文字聊天及不超过 25 MB 的加密 TXT 附件传输。用户已反馈文字聊天的不同网络测试成功；新文件功能尚待真实跨电脑测试。请先使用虚构消息和文件。

文件需手动接收，不自动预览或打开。“另存为”导出普通文件，不再受资料库口令保护。本版仅选择与导出 .txt 纯文本，每次新发送使用“文档-随机编号.txt”，原文件名不发送，本机文件不重命名。正文里的个人信息仍保留。发送前检查内容，统一为 UTF-8，不修改原文件。历史消息和已排队任务不改名。

聊天资料保存在 %LOCALAPPDATA%\PrivateChatDesktop。
升级与卸载不会主动删除这个目录。升级前请在旧版完成或取消非文本传输，本版不会清空旧的排队任务。遗忘口令无法找回。

安装包尚未取得发布者代码签名。如果 Windows 阻止运行，请核对下载来源和 SHA-256，不要关闭系统安全防护。

本版使用 Windows 网络隔离。请保持 Windows 防火墙及其服务开启；隔离无法启用时应用会停止启动。安装无需管理员权限，不修改全局防火墙规则。
